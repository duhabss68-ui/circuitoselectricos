# Circuitos eléctricos · 3.º A

Plataforma interactiva de la unidad de circuitos eléctricos (Tecnología, 3.er grado) de la Escuela Secundaria Francisco Severo Maldonado 66Y.
Prof. Nicolás Contreras Medina.

- Los alumnos entran con su usuario y contraseña.
- El maestro entra con el usuario `maestro` y ve el panel del grupo en tiempo real.
- Los datos viven en Supabase (proyecto `rushos-clases`), protegidos con reglas de seguridad por alumno.

Este repositorio solo contiene la página. No subas aquí listas de alumnos ni contraseñas.
